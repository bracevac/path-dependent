\title{\texorpdfstring{\lambdap}{lambda-p}: Paths through Dependent Pairs}
\author{Oliver Bra\v{c}evac}
\author{Martin Odersky}
\renewcommand{\shortauthors}{Bra\v{c}evac and Odersky}
\authorsaddresses{}

\begin{document}

\begin{abstract}
We present \lambdap{}, a calculus in which paths traverse immutable dependent
pairs. A pair member may depend on the first component and may contain either
a term reference or a type definition. The calculus distinguishes term
singleton types from abstract type selections. Conflating the two makes
singleton symmetry unsound: we give a closed, well-typed program that becomes
stuck. Dependent-pair covariance compares member signatures under the source
first-component type. Its semantic interpretation retains this comparison
until the concrete first component is known. We prove type safety in Lean.
\end{abstract}

\keywords{path-dependent types, dependent pairs, singleton types, type
soundness, Lean}

\section{Introduction}

A path-dependent type assigns a type component to a stable term path. DOT
presents this mechanism together with recursive objects, refinements,
intersections, unions, and declarative subtyping
\citep{amin2014foundations,rompf2016dot}. \lambdap{} isolates paths, abstract
type members, and dependency between the two components of a pair.

\lambdap{} is a call-by-value calculus in monadic normal form whose values are
functions and immutable dependent pairs. Paths are formed from variables,
first projections, and labelled selections. A pair stores a first component
together with either a term reference or a type definition, and its member
signature may depend on the first component. Chains of pairs encode records:
lookup resumes through the first component when the outer label differs. Term
singleton types record path identity, while abstract selections range over
explicitly checked lower and upper bounds. The static semantics includes
dependent functions and declarative subtyping with primitive transitivity;
evaluation combines big-step path resolution with a CK machine over an
append-only store.

For example, let \(r_1=\pairval{b}{a}{z}\) and
\(r_2=\pairval{r_1}{A}{T}\). Selection \(r_2.A\) hits the outer type member,
whereas \(r_2.a\) misses \(A\) and continues as \(r_2.1.a\), eventually
returning \(z\). The signature of the outer member may refer to its binder for
\(r_1\), so the same pair structure supports both record extension and
dependency on the preceding component.

The proof relies on two design choices. First, the singleton type
\(\sing{p}\), which expresses value identity, is distinct from the abstract
selection \(p.A\), which denotes a type between declared bounds. An earlier
version represented both with one constructor. We show that singleton
symmetry then turns abstract membership into a false path equality and yields
a closed stuck program.

Second, dependent-pair covariance compares members under the source
first-component type. The semantic interpretation records this premise as a
closure over its source environment and instantiates it when a runtime pair
exposes its first-component location. Coercion action is well founded because
the append-only store places both endpoints stored in a pair below the pair
cell in allocation order.

\paragraph{Contributions.}
The paper gives a closed counterexample showing that abstract membership
cannot justify singleton symmetry; a calculus that separates those notions
and retains dependent abstract members with explicit bound checks and
unrestricted dependent-pair covariance; and a type-safety proof based on
proof-relevant source derivations, store-local realization, runtime path
equivalence, and finite semantic coercions. The calculus, the regression
excluding the critical false alias, dependent-pair regressions at both member
kinds, and the safety proof are formalized in Lean 4
\citep{demoura2021lean4}. Recursive objects,
recursive types, mutation,
intersections, and unions lie outside the core language; program termination, type
inference, and elimination of primitive transitivity lie outside the present
development.

The binder \(x\) in a function scopes over its codomain. In
\(\pairty{x}{S}{a}{\tau}\), it scopes over the member signature \(\tau\).
We write \(\subst{\tau}{p}{x}\) for capture-avoiding opening. Terms are in
monadic normal form: pair components are variables, and both sides of an
application are paths.

The static semantics consists of precise path typing, subtyping,
well-formedness of member signatures, and term typing. The double colon marks a
synthesis judgment without subsumption; term typing admits subsumption through
\textsc{T-Sub}.

\section{Two design decisions}
\label{sec:pairs}

\subsection{Singletons and abstract selections}

The term singleton \(\sing{p}\) asserts value identity. In particular,
\textsc{S-Alias} is justified when precise typing says that one path has
another path's singleton type. An abstract selection \(p.A\) denotes an
unknown type between the bounds stored at \(A\); membership in \(p.A\)
carries no path-equality information.

In a precursor to \lambdap{}, both forms used one type constructor, so
singleton symmetry accepted either role. Let
\[
\begin{array}{rcl}
f &=& \lambda(x:\top).x,\\
q &=& \pairval{f}{A}{\top},\\
h &=& \lambda(z:q.A).q.
\end{array}
\]
The historical rules type the body of \(h\) by the chain
\[
  \sing{q}<:\top<:q.A<:\sing{z}.
\]
The last edge applies singleton symmetry to the context binding \(z:q.A\),
treating abstract membership as equality. The same rules accept \(f\) as an
argument of type \(q.A\). The application \(h\,f\) therefore evaluates to
\(q\) despite receiving the result type \(\sing{f}\).

Consequently, the closed program
\[
\begin{array}{l}
\mathbf{let}\ f=\lambda(x:\top).x\ \mathbf{in}\\
\mathbf{let}\ q=\pairval{f}{A}{\top}\ \mathbf{in}\\
\mathbf{let}\ h=\lambda(z:q.A).q\ \mathbf{in}\\
\mathbf{let}\ r=h\,f\ \mathbf{in}\ r\,f
\end{array}
\]
reaches an application whose operator location contains the pair \(q\). It is
neither final nor reducible. Every interval in the derivation is
\(\top..\top\), so all bounds pass the consistency check. An admissible
transitivity lemma would compose the same chain.

In the present syntax, a binding \(z:q.A\) cannot serve as a premise for
\textsc{S-Alias}. The mechanized regression proves that the critical
subtyping \(\sing{q}<:\sing{z}\) remains underivable even with primitive
transitivity.

The counterexample shows that singleton symmetry must distinguish term
identity from abstract membership. Separate constructors make this
distinction explicit.

\subsection{The pair rule}

Rule \textsc{S-Pair} compares the member signatures under a hypothetical
component \(x:S\). A semantic environment for \(\Gamma\) does not yet assign a
store location to \(x\), so this premise cannot be compiled immediately into a
store-local coercion. The interpretation retains the proof-relevant member
derivation together with the environment for \(\Gamma\). When coercion action
observes a source pair \(\pairval{y}{a}{\delta}\), realization supplies
\(\mathsf{Poss}_{\sigma}(y,S)\). Extending the retained environment with
\(x\mapsto y\) compiles the member premise to
\[
  \sigma\vdash
    \subst{\tau}{y}{x}\semmap\subst{\tau'}{y}{x}.
\]
This coercion acts on the stored member endpoint, while the first premise of
\textsc{S-Pair} maps the realization of \(y\) from \(S\) to \(S'\).

The rule derives the usual abstraction pattern directly. If
\(\Gamma\vdash p::P\), then
\[
\pairty{x}{\sing{p}}{A}{\sing{p}..\sing{p}}
\;<:\;
\pairty{x}{P}{A}{\bot..\sing{x}}.
\]
The first premise follows by singleton widening. Under
\(x:\sing{p}\), interval subtyping uses \(\bot<:\sing{p}\), singleton aliasing
to obtain \(\sing{p}<:\sing{x}\), and reflexivity for consistency of the source
bounds.

The mechanization also checks instances whose source first component is not a
singleton. In particular,
\[
\pairty{x}{\top}{a}{\sing{x}}
  <:\pairty{x}{\top}{a}{\top}
\qquad\text{and}\qquad
\pairty{x}{\top}{A}{\sing{x}..\sing{x}}
  <:\pairty{x}{\top}{A}{\bot..\top}.
\]
The second derivation exercises interval members. Its source type is inhabited
by the closed term
\[
\mathbf{let}\ y=\lambda(z:\top).z\ \mathbf{in}\
\bigl(\pairval{y}{A}{\sing{y}}:
  \pairty{x}{\top}{A}{\sing{x}..\sing{x}}\bigr).
\]
The lambda is subsumed to \(\top\) before it is bound. The pair ascription fixes
the dependent source type, and the displayed interval derivation gives the
whole term type \(\pairty{x}{\top}{A}{\bot..\top}\). Type safety is specialized
to this closed typing derivation in the mechanized regression.

\section{Soundness}
\label{sec:soundness}

The proof interprets source derivations as finite evidence over the current
store. Runtime path equivalence records equalities discovered by lookup,
semantic coercions interpret subtyping, and normalized evidence describes the
term and continuation of a machine state. The operational semantics remains
the machine in \cref{sec:dynamics}; coercions occur only in the metatheory.

Write \(\steps\) for the reflexive--transitive closure of \(\sstep\).
Thus \(\langle\varnothing,[\,],t\rangle\steps s\) means that execution of
\(t\) from the empty store and continuation reaches \(s\) in finitely many
machine steps. Type safety states non-stuckness for every such state.

\begin{theorem}[Type safety]
\label{thm:safety}
If \(\ctxempty\vdash t:T\) and
\(\langle\varnothing,[\,],t\rangle\steps s\), then
\(s\) is final or there exists \(s'\) such that \(s\sstep s'\).
\end{theorem}

The theorem concerns finite execution prefixes; termination lies outside its
scope. Allocation increases the scope of the store and weakens every type
that refers to an older location. Type extension is the least relation
generated by
\[
\inferrule
  { }
  {T\preceq T}
\qquad
\inferrule
  {T\preceq U}
  {T\preceq U^\uparrow}.
\]
Here \(U^\uparrow\) is weakening into the extended store scope. It has the
same concrete syntax as \(U\) in the named presentation used in the paper.
The proof maintains the state-evidence judgment
\(\Vdash\langle\sigma,K,t\rangle:T\), defined below.

\begin{theorem}[Reachable-state invariant]
\label{thm:reachable}
If \(\ctxempty\vdash t:T\) and
\(\langle\varnothing,[\,],t\rangle\steps s\), then for some \(U\),
\[
T\preceq U
\qquad\text{and}\qquad
\Vdash s:U.
\]
\end{theorem}

The invariant retains evidence for locations in environments, closures, path
derivations, and continuation frames. The construction proceeds through
generalized path resolution, store-local realization, finite coercions, and a
fundamental interpretation of proof-relevant source derivations.

\subsection{Realization and semantic coercions}
\label{sec:realization}

The judgments in
\cref{fig:fc-realization,fig:fc-coercions,fig:fc-deferred} are defined
simultaneously. A possible location records the evidence needed to use the
value stored there at a particular type. Function evidence contains the store
binding, a body closure at its introduction signature, a coercion from the
advertised domain to the stored domain, and a deferred codomain coercion.
Pair evidence contains the store binding and realizations of both components.
Singletons retain a resolution derivation, and a selection retains its stored
type together with a realization at that type.

Interval realization is the recursive point of the definition. A stored type
\(W\) realizes \(L..U\) by finite coercions from \(L\) to \(W\) and from
\(W\) to \(U\). These coercions are finite inductive data. Selection action
follows the stored lower or upper coercion. Transitivity composes actions, and
runtime conversion transports realizations along paths that co-resolve in the
store.

The codomain premise of function subtyping is suspended until application
supplies an argument location. A source deferred coercion closes a
proof-relevant subtyping derivation with the environment for its free
variables. Deferred coercions support the composition and narrowing required
when function coercions act on possible functions. Instantiation extends the
saved environment with the actual argument and compiles the source derivation.
Body closures use the same environment-passing construction for function and
let bodies.

Rule \textsc{M-Pair} retains its member premise in a separate dependent-member
closure. This closure has a single source constructor: it pairs the
proof-relevant derivation of
\(\Gamma,z:S\vdash\tau<:\tau'\) with an environment for \(\Gamma\). If a
source pair stored at \(r\) contains first component \(y\), rule
\textsc{P-Pair} supplies \(\mathsf{Poss}_{\sigma}(y,S)\). Instantiation maps
\(z\) to \(y\) and compiles the retained derivation. The resulting coercion
maps the member endpoint from \(\subst{\tau}{y}{z}\) to
\(\subst{\tau'}{y}{z}\); the first-component coercion independently maps
\(\mathsf{Poss}_{\sigma}(y,S)\) to
\(\mathsf{Poss}_{\sigma}(y,S')\).

Coercion action uses well-founded recursion because a member closure can
compile to a coercion that is not a subterm of the enclosing pair coercion.
Let \(n\) be the length of \(\sigma\). Runtime endpoints have stratum
\[
\mathsf{str}_{\sigma}(\mathsf{val}(x))=n-\mathsf{index}(x),
\qquad
\mathsf{str}_{\sigma}(\mathsf{type}(W))=0,
\]
where index zero denotes the newest store location. Allocation increments the
indices of old locations, leaving their strata unchanged. The append-only
store ensures that if
\(\sigma(r)=\pairval{y}{a}{\delta}\), then
\[
\mathsf{str}_{\sigma}(\mathsf{val}(y))
  <\mathsf{str}_{\sigma}(\mathsf{val}(r))
\quad\text{and}\quad
\mathsf{str}_{\sigma}(\mathsf{endpoint}(\delta))
  <\mathsf{str}_{\sigma}(\mathsf{val}(r)).
\]
Action of coercion \(c\) on endpoint \(e\) is defined using the lexicographic
measure \((\mathsf{str}_{\sigma}(e),|c|)\), where \(|c|\) is coercion-tree
size. Every recursive call outside the pair case keeps the endpoint fixed and
uses a proper subcoercion, decreasing \(|c|\). The pair case invokes action
once on the stored first component and once on the stored member endpoint.
Both calls decrease the primary stratum component. In particular, the second
call may use the newly compiled member coercion without requiring a structural
decrease from the enclosing coercion.

\begin{lemma}[Coercion compilation and action]
\label{lem:coercions}
Suppose \(\rho\models_{\sigma}\Gamma\).
\begin{enumerate}
\item If \(\Gamma\vdash_{\mathsf c}\tau_1<:\tau_2\), then
  \(\sigma\vdash\rho(\tau_1)\semmap\rho(\tau_2)\).
\item If \(\sigma\vdash\tau_1\semmap\tau_2\) and
  \(e\in\llbracket\tau_1\rrbracket_{\sigma}\), then
  \(e\in\llbracket\tau_2\rrbracket_{\sigma}\).
\item If \(\sigma\vdash_{z:S}T\defermap U\) and
  \(\mathsf{Poss}_{\sigma}(x,S)\), then
  \(\sigma\vdash\subst{T}{x}{z}\semmap\subst{U}{x}{z}\).
\item If \(\sigma\vdash_{z:S}\tau\membermap\tau'\) and
  \(\mathsf{Poss}_{\sigma}(x,S)\), then
  \(\sigma\vdash\subst{\tau}{x}{z}\semmap
    \subst{\tau'}{x}{z}\).
\end{enumerate}
\end{lemma}

The first clause compiles source subtyping. Its selection cases use the
coercions contained in interval realization, and its transitivity case builds
finite composition. The second clause is coercion action. The third is the
deferred-codomain instantiation used in dependent beta reduction, and the
fourth is dependent-member instantiation used by pair coercion action.

\subsection{Fundamental interpretation}

The interpretation is parameterized by the valuation that connects a source
scope to the current store. Extending an environment maps the newest source
variable to a location possible at the renamed binder type. This operation is
used when a deferred coercion, dependent-member closure, or body closure
receives its argument.

\begin{lemma}[Fundamental interpretation]
\label{lem:fundamental}
Suppose \(\rho\models_{\sigma}\Gamma\).
\begin{enumerate}
\item If \(\Gamma\vdash_{\mathsf c}p::\tau\), then for some endpoint \(e\),
  \(\sigma\vdash\rho(p)\resolve e\) and
  \(e\in\llbracket\rho(\tau)\rrbracket_{\sigma}\).
\item If \(\Gamma\vdash_{\mathsf c}\tau_1<:\tau_2\), then
  \(\sigma\vdash\rho(\tau_1)\semmap\rho(\tau_2)\).
\item If \(\Gamma\vdash_{\mathsf c}t:T\), then
  \(\sigma\Vdash_{\mathsf t}\rho(t):\rho(T)\).
\end{enumerate}
\end{lemma}

The path clause supplies the inversion required by lookup. When precise path
typing projects from or selects through a pair, realization of the receiver
exposes the corresponding store binding, first component, and member
endpoint. The stored member is opened at the concrete first location. Since
that location and the receiver's first projection co-resolve, runtime
conversion gives the type expected by the source derivation. The miss case
continues recursively through the realized first component. Thus a typed path
has a generalized resolution, and a proper path type yields the term-path
reduction used by the machine.

The term clause produces the normalized rules in
\cref{fig:fc-term-evidence}. Abstractions and let expressions retain body
closures. Subsumption compiles its source subtyping derivation and composes the
result with the final coercion already stored at the outer term constructor.
The empty valuation realizes the empty context, so a closed source derivation
immediately yields evidence for its initial machine state.

Coercion action gives the canonical forms used by progress. In particular,
if \(\mathsf{Poss}_{\sigma}(x,(z:S)\to U)\), then the only possible rule is
\textsc{P-Fun}; hence \(\sigma(x)=\lambda(z:A).t\) for some \(A,t\), together
with a body closure, a coercion \(S\semmap A\), and a deferred codomain
coercion. The pair case similarly exposes a stored pair and realizations of
its components. Both inversions follow directly from the corresponding
\(\mathsf{Poss}\) constructor.

\subsection{Normalized machine evidence}

The rules in
\cref{fig:fc-term-evidence,fig:fc-machine-evidence} form the invariant used by
the operational proof. Each term constructor retains its syntax-directed
premises and a final coercion to the advertised type. A path additionally
retains its reduction. A let frame retains the body closure and result
coercion that will be needed when its bound computation returns. Continuation
evidence composes these frames, and state evidence connects the current term
to the input type of its continuation.

Allocation shifts every old location. Runtime equality, environments,
possible locations, endpoint realizations, coercions, deferred coercions,
dependent-member closures, body closures, terms, and continuations are all
stable under this uniform weakening. A newly allocated value is possible at
the weakening of its advertised type, which supplies the fresh argument used
to resume the saved body closure.

\subsection{Progress and preservation}

\begin{theorem}[Progress]
\label{thm:progress}
If \(\Vdash s:T\), then \(s\) is final or there exists \(s'\) such that
\(s\sstep s'\).
\end{theorem}

\begin{theorem}[Preservation]
\label{thm:preservation}
If \(\Vdash s:T\) and \(s\sstep s'\), then for some \(U\),
\[
T\preceq U
\qquad\text{and}\qquad
\Vdash s':U.
\]
\end{theorem}

Progress inspects the outer constructor of normalized term evidence. A path
rule already contains its reduction. Intrinsic scoping makes lookup total for
every location in the store. A variable path is final under an empty
continuation and returns through a nonempty continuation. For an application,
the function path realizes a singleton at its resolved location; applying its
suffix coercion produces a possible function, whose canonical form exposes
the abstraction required by \textsc{E-App}. Syntactic values are final or
allocate, while lets and ascriptions take their administrative steps.

Preservation follows the six transition rules in \cref{fig:dynamics}.
For \textsc{E-App}, function and argument path evidence yield possible
locations at the advertised function domain and argument type. The domain
coercion checks the concrete argument at the closure's stored domain. Applying
the body closure gives its result at the argument location, and instantiating
the deferred codomain coercion gives the advertised codomain there. Runtime
equality between the source argument path and that location transports the
dependent result back to \(\subst{U}{q}{z}\), after which the application's
final coercion applies.

For \textsc{E-Path}, co-resolution of \(p\) and its result \(x\) converts
\(\sing{p}\) to \(\sing{x}\) and composes with the saved suffix. The
\textsc{E-Let} step moves the saved body closure and result coercion into a
frame. The \textsc{E-Return} step applies such a closure to the returned
location and composes the frame coercion. For \textsc{E-Alloc}, normalized
value evidence makes the fresh location possible at the weakened bound type;
the frame closure is applied there, and the remaining continuation and result
type are weakened into the larger store scope. Finally, \textsc{E-Ascribe}
removes the ascription and composes its saved coercion.

Iterating preservation proves \cref{thm:reachable}. Progress at the resulting
state proves \cref{thm:safety}.

\section{Related work}

DOT combines abstract type members with recursive objects, refinements,
intersections, and a rich subtyping lattice
\citep{amin2014foundations,rompf2016dot}. Its soundness proofs must control
which abstract bounds can be exposed in arbitrary contexts. The tight-typing
account of \citet{rapoport2017simple}, for example, factors reasoning through
inert contexts in which runtime values admit strong inversion principles.

For \lambdap{}, store-local possible evidence provides the required inversion
principle. A possible function or pair retains its concrete store binding and
the evidence required by its introduction form, while semantic coercions
account for every subsequent use of subtyping. Primitive transitivity and
abstract selection are therefore interpreted without a separate inert or
tight-typing judgment.

pDOT adds arbitrary-length paths and singleton types to recursive objects and
gives a Coq-mechanized safety proof \citep{rapoport2019pdot}. \lambdap{}
represents record extension by dependent-pair chains, with explicit hit and
miss rules for static selection and dynamic lookup. Removing recursive
objects, intersections, and unions leaves path lookup as a distinct obligation
in the safety proof.

\section{Conclusion}

\lambdap{} isolates paths, dependent pairs, and abstract type members. Its
counterexample shows that abstract membership cannot justify singleton
symmetry. The safety proof interprets proof-relevant source derivations using
store-local realization, runtime path equivalence, deferred evidence, and
finite semantic coercions. Unrestricted dependent-pair covariance is validated
by closing the member derivation over its source environment and instantiating
it at the stored first component. The append-only allocation order and
coercion-tree size provide the lexicographic measure for coercion action.
