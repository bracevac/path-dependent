\title{Semantic Coercions for Paths through Dependent Pairs}
\author{Oliver Bra\v{c}evac}
\author{Martin Odersky}
\renewcommand{\shortauthors}{Bra\v{c}evac and Odersky}
\authorsaddresses{}

\begin{document}

\begin{abstract}
We study a small call-by-value calculus of path-dependent types in which
paths traverse immutable dependent pairs. Pairs carry term members or
abstract type members, and their second component may mention the first. The
central subtyping rule is covariant in both components: it compares dependent
members under the source first-component type. This rule resists the usual
syntax-directed preservation argument because its member premise must be
instantiated at a concrete store location that is unavailable in the source
derivation.

The soundness proof interprets each subtyping derivation as a finite,
store-indexed semantic coercion. A coercion maps realizations of its source
type to realizations of its target type. Function codomains and pair members
are retained as closures until execution supplies the corresponding
location. For a pair coercion, the saved member derivation is instantiated at
the first component stored in the pair and then applied to the stored member
endpoint. The action is well founded because both endpoints named by a stored
pair have lower endpoint stratum than the pair cell. We give the complete
calculus, operational semantics, coercion construction, machine invariant,
and progress and preservation theorems. The development is mechanized in
Lean 4.
\end{abstract}

\keywords{path-dependent types, dependent pairs, subtyping, semantic
coercions, type soundness, Lean}

\section{Introduction}

Path-dependent types associate type information with stable term paths. DOT
calculi place this mechanism in a rich object calculus with recursive self
types, refinements, intersections, and abstract type members
\citep{amin2014foundations,rompf2016dot}. The interaction among those
features has led to several distinct soundness arguments. The calculus in
this paper, \lambdap{}, isolates a smaller question: how much of paths and
abstract type selection can be based on ordinary dependent pairs?

A \lambdap{} value is an abstraction or an immutable pair
\(\pairval{y}{a}{\delta}\). Its first component is a store location. The
second component is either another location or a type definition, and its
signature may refer to the first component. Paths consist of variables,
first projections, and labelled selections. A failed selection continues
through the first component, allowing nested pairs to represent extensible
records. Term singleton types \(\sing{p}\) record path identity. Abstract
selections \(p.A\) range between a stored lower and upper bound. The language
also contains dependent functions, declarative subtyping with primitive
transitivity, and explicit consistency premises for interval bounds.

The difficult rule is covariance of dependent pairs:
\[
\inferrule*[right=\textsc{S-Pair}]
  {\Gamma\vdash S<:S'
   \\
   \Gamma,x:S\vdash D<:D'}
  {\Gamma\vdash
    \pairty{x}{S}{a}{D}<:\pairty{x}{S'}{a}{D'}}.
\]
The source pair supplies a component of type \(S\), so \(S\) is the natural
assumption for comparing the members. At run time, however, the member
signature is opened with the concrete location \(y\) stored in the pair. A
proof of preservation must use the second premise at that location and must
relate source paths to the endpoints reached by store lookup.

We make this use of subtyping evidence explicit in the metatheory. Under an
environment mapping source variables to locations, a subtyping derivation
compiles to a semantic coercion
\[
  \sigma\vdash D\coerce D'.
\]
Its meaning is operational at the proof level: whenever a location or stored
type endpoint realizes \(D\), coercion action produces a realization of
\(D'\). Transitivity becomes coercion composition. Rules for singleton and
abstract selection retain the path resolutions and interval evidence needed
by their actions. Function and pair rules retain dependent premises until a
concrete binder location is known.

For \textsc{S-Pair}, compilation produces a coercion for \(S<:S'\) and a
closure containing the derivation of \(D<:D'\). Acting on a pair at location
\(z\) exposes its first component \(y\) and its stored definition \(\delta\).
The first coercion maps the realization of \(y\) from \(S\) to \(S'\). The
closure extends its saved environment by \(x\mapsto y\), producing a
coercion from \(D[y/x]\) to \(D'[y/x]\), which acts on the endpoint of
\(\delta\). This dynamically produced coercion is not a structural child of
the pair coercion. The first component \(y\) and any location stored in
\(\delta\) are older than \(z\), while a stored type endpoint has the base
stratum. Coercion action uses the
lexicographic measure consisting of endpoint stratum and coercion-tree size.

The proof uses these coercions only as semantic evidence. Programs and
machine states contain the source terms given in \cref{sec:calculus};
execution performs no casts or type checks. Typed intermediate calculi such
as System FC instead place equality evidence and casts in the intermediate
program and erase them before execution \citep{sulzmann2007systemfc}.

The contributions are:
\begin{itemize}
\item a small calculus combining arbitrary stable paths, term singletons,
  abstract type selections, dependent functions, and dependent pairs with
  proper or interval members;
\item a store-indexed coercion interpretation of its full declarative
  subtyping relation, including primitive transitivity and unrestricted
  dependent-pair covariance;
\item a well-founded action for pair coercions based on the allocation order
  of immutable stores; and
\item a Lean 4 mechanization of path resolution, coercion construction and
  action, a syntax-directed machine invariant, progress, preservation, and
  non-stuckness of every finite execution prefix.
\end{itemize}

The result is type safety for the calculus as presented. It does not establish
normalization, decidability of subtyping, or admissibility of transitivity.

\section{The calculus}
\label{sec:calculus}

\lambdap{} isolates path-dependent types in a call-by-value calculus with
immutable dependent pairs.  Terms are in monadic normal form: applications
take paths as operands, and a pair contains a location as its first component
together with either another location or a type definition.  The operational
semantics combines big-step path lookup with a CK machine.

\subsection{Syntax}
\label{sec:syntax}

\Cref{fig:source-syntax} gives the source syntax.  A member signature is
either a proper type or an interval.  The two forms belong to distinct sorts,
which the mechanization tracks intrinsically; the sort index is suppressed in
the paper.  A location definition is paired with a proper signature, whereas
a type definition is paired with an interval signature.  Labels occupy one
syntactic name space.  We conventionally use uppercase letters for type
member labels when this improves readability.

The binder in a function scopes over its codomain.  The binder \(x\) in
\(\pairty{x}{S}{a}{\tau}\) scopes over the member signature \(\tau\); it
denotes the first component of the pair.  We write
\(\subst{\tau}{p}{x}\) for capture-avoiding opening.  Singleton types
\(\sing{p}\) record term identity.  An abstract selection \(p.A\) denotes an
unknown type constrained by the interval stored at \(A\).

The Lean development represents scopes intrinsically with de Bruijn indices.
The named presentation used here is equivalent.  In particular, a type
stored in \(\Gamma\) is weakened through the bindings added after it.  We
write \(\Gamma(x)=T\) for context lookup.

\label{sec:static-semantics}

well-formedness, and term typing.  Precise path typing synthesizes either a
proper type or an interval and admits no subsumption.  Term typing assigns a
singleton type to a path and provides subsumption separately.

intrinsically scoped implementation, the body already lives in the extended

\section{Proof obligations}
\label{sec:obligations}

\subsection{Term aliases and abstract selections}

The distinction between singleton types and abstract selections is required
by the alias rule. A premise \(\Gamma\vdash p::\sing{q}\) says that \(p\)
has the singleton type of \(q\), and therefore justifies reversing the alias:
\(\sing{q}<:\sing{p}\). A premise \(\Gamma\vdash p::q.A\) only places the
type of \(p\) between the bounds declared by \(q.A\).

An earlier syntax used one type constructor for both roles. Singleton
symmetry could then consume an abstract-membership premise. With
\[
  f=\lambda(x:\top).x,
  \qquad q=\pairval{f}{A}{\top},
  \qquad h=\lambda(z:q.A).q,
\]
the conflated rules admitted the chain
\[
  \sing{q}<:\top<:q.A<:\sing{z}.
\]
They consequently assigned \(\sing{f}\) to \(h\,f\), although the
application returns \(q\). The complete closed program is
\[
\begin{array}{l}
\mathbf{let}\ f=\lambda(x:\top).x\ \mathbf{in}\\
\mathbf{let}\ q=\pairval{f}{A}{\top}\ \mathbf{in}\\
\mathbf{let}\ h=\lambda(z:q.A).q\ \mathbf{in}\\
\mathbf{let}\ r=h\,f\ \mathbf{in}\ r\,f.
\end{array}
\]
Evaluation binds \(r\) to the pair \(q\), while the erroneous singleton
type makes \(r\) usable as the function \(f\). The final application is
stuck because its operator cell contains a pair. Separate constructors prevent an abstract
member assumption from serving as evidence of path identity. All intervals
in the example may have equal bounds, so the bounds-consistency premises do
not address this problem.

\subsection{The open premise of pair subtyping}

The second premise of \textsc{S-Pair} is a derivation under a hypothetical
variable. A source environment for \(\Gamma\) contains no interpretation for
that variable. Compiling the premise immediately would require choosing a
location before the source pair is observed. Ordinary substitution lemmas
also leave the critical semantic fact unstated: the chosen location must
realize \(S\), and the member endpoint must realize the source member opened
at the same location.

The run-time realization of a pair contains exactly these facts. If
\(\sigma(z)=\pairval{y}{a}{\delta}\) realizes
\(\pairty{x}{S}{a}{D}\), then \(y\) realizes \(S\) and the endpoint stored
by \(\delta\) realizes \(D[y/x]\). The coercion interpretation retains the
member derivation until this evidence becomes available, permitting the
general rule to vary both the first component and the member signature.

\subsection{Proof architecture}

The soundness construction has four layers.
\begin{enumerate}
\item Generalized path resolution follows both term and type members.
  Store-indexed path equality records paths with the same resolution and
  induces conversion on types containing those paths.
\item Location and endpoint realization describe the run-time observations
  justified by a type or member signature.
\item Semantic coercions compile source subtyping derivations and act on
  endpoint realizations. Closures account for premises beneath binders.
\item Syntax-directed evidence for terms, frames, continuations, and states
  carries a trailing coercion at every source of subsumption. This evidence
  is the invariant used by progress and preservation.
\end{enumerate}
Each judgment is defined in the following sections before it is used in a
theorem statement.

\subsection{Runtime path equality}

Generalized resolution may end at a value location or at a stored type. Two
paths are \emph{co-resolved} when they reach the same endpoint:
\[
  p\mathrel{\bowtie_{\sigma}}q
  \quad\Longleftrightarrow\quad
  \exists e.\;\sigma\vdash p\resolve e
    \ \land\ \sigma\vdash q\resolve e.
\]
Runtime path equality is the finite congruence generated by co-resolution.
The context in \textsc{RE-Cong} is a one-hole path context, written \(C[p]\).

\subsection{Environments, locations, and endpoints}

A valuation \(\rho\) maps each source variable to a location in the current
store and acts by renaming on paths, types, and terms. Environment
satisfaction is defined pointwise:
\[
  \rho\realizes_{\sigma}\Gamma
  \quad\Longleftrightarrow\quad
  \forall x\in\mathsf{dom}(\Gamma).\;
  \sigma\realizes\rho(x):\rho(\Gamma(x)).
\]
The judgment \(\sigma\realizes x:T\) is semantic typing of a store location.
Endpoint realization \(\sigma\realizes e:D\) extends it to type endpoints.
The auxiliary body closure \(\bodycl{\sigma}{S}{t}{T}\) retains a source
typing derivation for \(t\) and an environment for its free variables; its
formal argument remains unassigned until application. In
\textsc{BC-Source}, \(\mathcal D\) names the displayed source typing
derivation and \(\rho^+\) is the valuation lifted through its binder.

Realization, semantic environments, body closures, coercions, and the two
binder closures are defined simultaneously as strictly positive inductive
families. \Cref{fig:realization,fig:coercions,fig:coercion-closures} separate
their constructors according to their role in the proof.

The complete realization rules appear in \cref{fig:realization}. Deferred
coercions in the function rule are defined in \cref{sec:coercions}. For
\textsc{L-Fun}, the stored abstraction accepts \(A\) and has body type \(B\).
The advertised function accepts \(S\): a coercion maps an \(S\)-argument to
\(A\), and the deferred coercion maps the opened body result to the advertised
codomain. For \textsc{L-Pair}, \(\mathsf{endpoint}(\delta)\) is \(\loc z\) when
\(\delta=z\), and \(\typeep W\) when \(\delta\) is a type definition \(W\).

\begin{lemma}[Typed path resolution]
\label{lem:typed-resolution}
If \(\rho\realizes_{\sigma}\Gamma\) and
\(\Gamma\vdash p::D\), then there is an endpoint \(e\) such that
\(\sigma\vdash\rho(p)\resolve e\) and
\(\sigma\realizes e:\rho(D)\).
\end{lemma}

The proof follows the precise path-typing derivation. The matching-selection
case converts the member realization from opening at the stored location to
opening at the receiver's first projection, using runtime equality. The
missed-selection case uses congruence of resolution after both receiver paths
reach the same first-component location. This lemma supplies the path
inversion that big-step lookup requires.

\section{Semantic coercions}
\label{sec:coercions}

For a fixed store, a semantic coercion
\(
  \sigma\vdash D_1\coerce D_2
\)
is finite evidence that endpoint realization at \(D_1\) can be transformed
into endpoint realization at \(D_2\). The two signatures are either both
proper types or both intervals. Coercions belong to the metatheory and do not
extend the term or machine syntax.

The complete coercion judgment appears in \cref{fig:coercions}. Rule
\textsc{M-Conv} embeds the runtime conversion of
\cref{fig:runtime-conv}. The singleton rules retain concrete resolution
evidence. The selection rules retain the stored type \(W\) and the
corresponding half of its interval realization. Function codomains and pair
members remain open until a runtime location is available; their evidence is
recorded by the closure judgments in \cref{fig:coercion-closures}.

\subsection{Construction from source subtyping}
\label{sec:coercion-construction}

The mechanization constructs coercions from proof-relevant source
derivations. We write
\(
  \mathcal D::\Gamma\vdash D_1<:D_2
\)
when \(\mathcal D\) names such a derivation. Its constructors are exactly the
source subtyping rules, and erasure returns the corresponding declarative
derivation. Every declarative derivation has a proof-relevant representative.

Coercion construction invokes typed resolution in the path-dependent cases.
By \cref{lem:typed-resolution}, resolving a precisely typed path under a
semantic environment produces both a runtime endpoint and realization of its
precise signature.

\begin{lemma}[Coercion construction]
\label{lem:coercion-construction}
If \(\rho\realizes_\sigma\Gamma\) and
\(\mathcal D::\Gamma\vdash D_1<:D_2\), then
\[
  \mathsf{compile}_{\rho,\sigma}(\mathcal D)
    :\sigma\vdash\rho(D_1)\coerce\rho(D_2).
\]
\end{lemma}

The construction follows \(\mathcal D\). Reflexivity, transitivity, bottom,
and top select the corresponding coercion constructors. Singleton widening
uses typed resolution to obtain the resolved location and its realization at
the target type. In the alias case, realization of the precise singleton
type supplies a second resolution to the same location.

Suppose a selection premise has precise signature \(L..U\). Typed resolution
produces a type \(W\) and evidence
\[
  \sigma\vdash\rho(p.A)\resolve\typeep W,
  \qquad
  \sigma\vdash\rho(L)\coerce W,
  \qquad
  \sigma\vdash W\coerce\rho(U).
\]
The lower-selection case retains the first coercion; the upper-selection case
retains the second. Function subtyping compiles its domain premise and uses
\textsc{D-Source} for its codomain. Pair subtyping compiles its first premise
and uses \textsc{MC-Source} for its member premise. Interval subtyping
recursively compiles all three premises.

Supplying a concrete binder location extends the saved environment and
resumes the construction. In the following statement, \(z\) denotes the
distinguished variable under which the deferred signatures were formed.

\begin{lemma}[Closure instantiation]
\label{lem:coercion-instantiation}
The following operations are defined.
\begin{enumerate}
\item If \(C:\sigma\vdash_S T\defermap U\) and
  \(R:\sigma\realizes x:S\), then
  \[
    \mathsf{inst}_{\defer}(C,R):
      \sigma\vdash\subst{T}{x}{z}\coerce\subst{U}{x}{z}.
  \]
\item If \(M:\sigma\vdash_S D\membermap D'\) and
  \(R:\sigma\realizes x:S\), then
  \[
    \mathsf{inst}_{\member}(M,R):
      \sigma\vdash\subst{D}{x}{z}\coerce\subst{D'}{x}{z}.
  \]
\end{enumerate}
\end{lemma}

Deferred instantiation follows its evidence. Composition is instantiated
componentwise, and a scoped conversion is opened with \(x\). In the
\textsc{D-Narrow} case, the domain coercion first maps the supplied location
realization to the domain expected by the nested deferred coercion. A source
closure extends its saved environment by \(z\mapsto x\) and invokes
\cref{lem:coercion-construction}. Member instantiation performs the same
extension for \textsc{MC-Source}.

\subsection{Action on endpoint realization}
\label{sec:coercion-action}

Coercions act on the endpoint realization defined in
\cref{fig:realization}.

\begin{lemma}[Coercion action]
\label{lem:coercion-action}
If \(C:\sigma\vdash D_1\coerce D_2\) and
\(R:\sigma\realizes e:D_1\), then
\[
  \mathsf{act}_\sigma(C,R):\sigma\realizes e:D_2.
\]
Consequently, a coercion \(\sigma\vdash S\coerce T\) maps
\(\sigma\realizes x:S\) to \(\sigma\realizes x:T\).
\end{lemma}

Identity returns its argument, and composition applies its coercions in
order. Rule \textsc{M-Conv} transports realization along runtime conversion.
There is no realization constructor for \(\bot\), while \textsc{M-Top}
returns \textsc{L-Top}. In \textsc{M-Widen}, determinism of resolution
identifies the location carried by the source singleton with the location
stored in the coercion. Rule \textsc{M-Alias} uses the same argument to
replace one singleton resolution by the other.

For \textsc{M-Sel-Lo}, action maps a location realization at \(L\) to one at
the resolved witness type \(W\), then constructs \textsc{L-Select}. For
\textsc{M-Sel-Hi}, inversion of \textsc{L-Select} exposes a realization at
the witness type. Determinism identifies its stored type with \(W\), after
which the upper coercion produces a realization at \(U\).

Function action preserves the stored abstraction and body closure. Suppose
the source \textsc{L-Fun} evidence contains
\[
  C_{\mathsf{in}}:\sigma\vdash S\coerce A,
  \qquad
  C_{\mathsf{out}}:\sigma\vdash_S B\defermap T.
\]
Acting with \textsc{M-Fun}, whose premises are
\[
  C_{\mathsf{dom}}:\sigma\vdash S'\coerce S,
  \qquad
  C_{\mathsf{cod}}:\sigma\vdash_{S'}T\defermap T',
\]
produces the input coercion
\[
  C_{\mathsf{dom}};C_{\mathsf{in}}:
    \sigma\vdash S'\coerce A
\]
and the deferred output coercion
\[
  \mathsf{narrow}(C_{\mathsf{dom}},C_{\mathsf{out}});
  C_{\mathsf{cod}}:
    \sigma\vdash_{S'}B\defermap T'.
\]
These are the two coercion fields required to reconstruct \textsc{L-Fun} at
the target function type.

For interval coercions, let \(\typeep W\) realize \(L..U\) through
\[
  C_{LW}:\sigma\vdash L\coerce W,
  \qquad
  C_{WU}:\sigma\vdash W\coerce U.
\]
Action of \textsc{M-Bounds} returns the target realization through
\[
  C_{L'L};C_{LW}:\sigma\vdash L'\coerce W,
  \qquad
  C_{WU};C_{UU'}:\sigma\vdash W\coerce U'.
\]
The consistency coercion from \(L\) to \(U\) remains part of the coercion
constructor. Action on an existing interval realization uses its lower and
upper evidence directly.

\subsection{Action for the general pair rule}
\label{sec:coercion-pair}

The source rule changes both the first-component type and the dependent
member signature:
\[
\inferrule*[right=\textsc{S-Pair}]
  {\mathcal D_S::\Gamma\vdash S<:S'
   \\
   \mathcal D_M::\Gamma,z:S\vdash D<:D'}
  {\Gamma\vdash
    \pairty{z}{S}{a}{D}<:
    \pairty{z}{S'}{a}{D'}}.
\]
Fix \(\rho\realizes_\sigma\Gamma\), and abbreviate
\[
  \bar S=\rho(S),\qquad
  \bar S'=\rho(S'),\qquad
  \bar D=\rho^+(D),\qquad
  \bar D'=\rho^+(D').
\]
Compilation proceeds in three steps.
\begin{enumerate}
\item The first premise is compiled immediately:
  \[
    C_S=\mathsf{compile}_{\rho,\sigma}(\mathcal D_S):
      \sigma\vdash\bar S\coerce\bar S'.
  \]
\item Rule \textsc{MC-Source} packages \(\mathcal D_M\) with the environment
  for \(\Gamma\):
  \[
    M:\sigma\vdash_{\bar S}\bar D\membermap\bar D'.
  \]
\item Rule \textsc{M-Pair} combines them:
  \[
    \mathsf{pair}(C_S,M):
    \sigma\vdash
      \pairty{z}{\bar S}{a}{\bar D}\coerce
      \pairty{z}{\bar S'}{a}{\bar D'}.
  \]
\end{enumerate}

Consider action on a source pair endpoint:
\[
  \sigma\realizes\loc r:\pairty{z}{\bar S}{a}{\bar D}.
\]
Inversion of \textsc{E-Loc} and \textsc{L-Pair} yields
\[
  \sigma(r)=\pairval{y}{a}{\delta},
  \qquad
  R_y:\sigma\realizes y:\bar S,
  \qquad
  R_\delta:
    \sigma\realizes\mathsf{endpoint}(\delta):
      \subst{\bar D}{y}{z}.
\]
Pair action continues as follows.
\begin{enumerate}
\item Apply \(C_S\) to \(R_y\), obtaining
  \(R_y':\sigma\realizes y:\bar S'\).
\item Instantiate \(M\) with the original realization \(R_y\). The saved
  environment is extended by \(z\mapsto y\), and \(\mathcal D_M\) compiles
  to
  \[
    C_M:\sigma\vdash
      \subst{\bar D}{y}{z}\coerce
      \subst{\bar D'}{y}{z}.
  \]
  The original realization has type \(\bar S\), matching the source
  assumption in the second premise of \textsc{S-Pair}.
\item Apply \(C_M\) to \(R_\delta\), obtaining
  \[
    R_\delta':
      \sigma\realizes\mathsf{endpoint}(\delta):
        \subst{\bar D'}{y}{z}.
  \]
\item Reuse the store binding with \(R_y'\) and \(R_\delta'\) to reconstruct
  \[
    \sigma\realizes r:\pairty{z}{\bar S'}{a}{\bar D'},
  \]
  and hence endpoint realization at the target pair type.
\end{enumerate}

The construction covers both forms of pair member. For a proper member,
\(\mathsf{endpoint}(\delta)\) is a location and \(D,D'\) are proper types. For an
interval member, it is a type endpoint and \(D,D'\) are intervals.

\subsection{Well-foundedness of coercion action}
\label{sec:coercion-termination}

Transitivity and selection recurse on structural subcoercions. Pair action
also invokes the coercion obtained by instantiating its member closure. This
coercion is constructed at the point of use and can be larger than the
enclosing pair coercion. The allocation order of the immutable store provides
the required decrease.

Let \(n\) be the length of \(\sigma\). Define the stratum of a runtime
endpoint by
\[
  \mathsf{str}_\sigma(\loc x)=n-\mathsf{index}(x),
  \qquad
  \mathsf{str}_\sigma(\typeep W)=0,
\]
where index zero denotes the newest store cell. Allocation increments both
the store length and the index of every old location, so weakening preserves
stratum. If
\[
  \sigma(r)=\pairval{y}{a}{\delta},
\]
then the store binding entails
\[
  \mathsf{str}_\sigma(\loc y)
    <\mathsf{str}_\sigma(\loc r),
  \qquad
  \mathsf{str}_\sigma(\mathsf{endpoint}(\delta))
    <\mathsf{str}_\sigma(\loc r).
\]
For an interval member the second endpoint is a type endpoint and has stratum
zero. For a proper member it is an older location named by the stored pair.

The secondary measure is coercion-tree size:
\[
\begin{array}{rcl}
|\mathsf{refl}|=|\mathsf{conv}|=|\mathsf{bot}|=|\mathsf{top}|
  &=&1,\\
|\mathsf{widen}|=|\mathsf{alias}|&=&1,\\
|\mathsf{trans}(C_1,C_2)|&=&|C_1|+|C_2|+1,\\
|\mathsf{selLo}(C)|=|\mathsf{selHi}(C)|&=&|C|+1,\\
|\mathsf{fun}(C,F)|=|\mathsf{pair}(C,M)|&=&|C|+1,\\
|\mathsf{bounds}(C_1,C_2,C_3)|
  &=&|C_1|+|C_2|+|C_3|+1.
\end{array}
\]
Resolution witnesses and closures do not contribute to this structural
size. Coercion action is defined by well-founded recursion on
\[
  \bigl(\mathsf{str}_\sigma(e),|C|\bigr)
\]
in lexicographic order. In \textsc{M-Trans}, \textsc{M-Sel-Lo}, and
\textsc{M-Sel-Hi}, the endpoint is unchanged and the recursive coercion is a
proper subterm, decreasing the secondary component. In \textsc{M-Pair},
action on \(C_S\) moves from \(\loc r\) to \(\loc y\), and action on the
instantiated member coercion moves to \(\mathsf{endpoint}(\delta)\). Both calls
strictly decrease the primary component, independently of coercion size.
These are all recursive calls in coercion action.

\section{The machine invariant}
\label{sec:invariant}

\subsection{Syntax-directed run-time evidence}

Source typing permits subsumption at any depth. Direct inversion of that
judgment therefore exposes an arbitrary final \textsc{T-Sub} derivation. The
machine invariant uses syntax-directed evidence with one trailing semantic
coercion at every term constructor. We write
\(\sigma\vdash_{V}v:T\) for values and
\(\sigma\vdash_{R}t:T\) for run-time terms. These judgments are evidence in
the metatheory; they do not extend the machine syntax.

\Cref{fig:term-evidence} gives all constructors. The source types in the two
pair-value rules are their precise introduction types. In
\textsc{RT-Let}, \(U\) is independent of the let binder and the body closure
therefore advertises \(\up U\). In \textsc{RT-Ascribe}, \(A\) is the type
written in the term.

\subsection{Interpretation of typing derivations}

The mechanization represents the four declarative source judgments by
proof-relevant derivation objects with exactly the constructors shown in
\cref{sec:calculus}. Erasing such an object returns the corresponding
declarative derivation, and every declarative derivation has an erasure
preimage. This representation permits recursive construction of the
store-local evidence.

The interpretations of path typing and subtyping are
\cref{lem:typed-resolution,lem:coercion-construction}. Term typing follows the
same derivation-directed pattern. Abstractions and let bodies become body
closures. Pair introductions use reflexive trailing coercions. Application
combines the interpreted operator and operand. Subsumption compiles its
subtyping premise and appends the resulting coercion.

\begin{lemma}[Semantic typing]
\label{lem:semantic-typing}
If \(\rho\realizes_{\sigma}\Gamma\) and
\(\Gamma\vdash t:T\), then
\(\sigma\vdash_R\rho(t):\rho(T)\).
\end{lemma}

For the empty context and store, combining the lemma with \textsc{RK-Hole}
at reflexivity gives evidence for the initial state
\[
  \mathsf{initial}(t)=\langle\varnothing,[\,],t\rangle.
\]
This definition is used in all closed safety statements below.

\subsection{Progress}

Term evidence for a path \(p:T\), together with
\(\sigma\vdash p\vres x\), yields \(\sigma\realizes x:T\): construct the
singleton realization from the reduction and apply the trailing coercion.
This observation supplies canonical forms for applications. If the operator
has a function type, inversion of \textsc{L-Fun} produces an abstraction at
the resolved location.

All remaining progress cases follow the outer term constructor. A
non-variable path reduces to its location; a variable is final under an empty
continuation or returns through a let frame. Values are final under an empty
continuation and allocate under a frame. Let expressions push a frame, and
ascriptions step to their enclosed term.

\begin{theorem}[Progress]
\label{thm:progress}
If \(\sigma\vdash c:T\), then either \(\final(c)\) or there is a state
\(c'\) such that \(c\sstep c'\).
\end{theorem}

\subsection{Preservation}

Allocation changes the intrinsic scope of the store. Let
\(T\preceq U\) mean that \(U\) is obtained from \(T\) by zero or more
weakenings:
\begin{mathpar}
\inferrule*[right=\textsc{X-Refl}]
  {}{T\preceq T}
\and
\inferrule*[right=\textsc{X-Alloc}]
  {T\preceq U}{T\preceq\up U}.
\end{mathpar}
Only \textsc{E-Alloc} adds one weakening.

\begin{theorem}[One-step preservation]
\label{thm:preservation}
If \(\sigma\vdash c:T\) and \(c\sstep c'\), then there is a type \(U\) in
the scope of \(c'\) such that \(T\preceq U\) and \(c'\) has state evidence
at \(U\).
\end{theorem}

The application case contains the essential dependent reasoning. Suppose
\(p\) resolves to \(f\) and \(q\) resolves to \(y\). Applying the operator's
trailing coercion to the singleton realization of \(f\) yields location
realization at a function type. Rule \textsc{L-Fun} exposes the stored
abstraction, a body closure, an input coercion, and a deferred result
coercion. The argument realization is mapped to the abstraction's stored
domain, after which the body closure is instantiated at \(y\). Instantiating
the deferred coercion maps the resulting body type to the advertised
codomain opened at \(y\). Finally, the runtime equality
\(q\equiv_{\sigma}y\) converts that codomain to the source result opened at
\(q\), and the application evidence's trailing coercion supplies the final
type.

For a path step, \(p\) reduces to \(x\). The target term has the precise type
\(\sing{x}\). Runtime equality gives a conversion from \(\sing{x}\) to
\(\sing{p}\), which composes with the saved path coercion. Let-push moves the
saved body closure into a frame. Return instantiates that closure with the
returned location. Ascription composes its trailing coercion. Allocation
turns value evidence into realization evidence for the fresh location and
weakens every store-local proof object retained by the continuation and body.

\subsection{Finite executions}

Iterating \cref{thm:preservation} transports initial state evidence through
any finite execution. Applying \cref{thm:progress} at the endpoint gives the
standard non-stuckness statement.

\begin{theorem}[Finite preservation]
\label{thm:finite-preservation}
If \(\ctxempty\vdash t:T\) and
\(\mathsf{initial}(t)\steps c\), then there is a type \(U\) in the final
store scope such that \(T\preceq U\) and \(c\) has state evidence at \(U\).
\end{theorem}

\begin{theorem}[Type safety]
\label{thm:safety}
If \(\ctxempty\vdash t:T\) and
\(\mathsf{initial}(t)\steps c\), then \(c\) is final or can take a step.
\end{theorem}

The theorem quantifies over arbitrary finite prefixes. Divergent programs are
permitted; no endpoint of a finite prefix is stuck.

\section{Mechanization and regression examples}
\label{sec:mechanization}

The Lean 4 development \citep{demoura2021lean4} is intrinsically scoped.
Syntax carries the exact
number of available variables, contexts and stores share that scope, and
allocation changes it from \(n\) to \(n+1\). The paper suppresses the
mechanization's two-valued index distinguishing proper members from interval
members. The index rules out mismatched signatures and definitions; no
proof argument depends on its value.

The proof contains the complete static semantics and CK machine from
\cref{sec:calculus}; it imports no earlier \lambdap{} development. The main
formal result is the specialization of \cref{thm:safety} to declarative
typing. Auxiliary files establish scoped renaming and substitution,
determinism and weakening of resolution, conversion under binders,
weakening of all semantic evidence across allocation, and the store-order
lemmas used by coercion action. These lemmas support the paper-level results
without changing their statements.

Two subtyping regressions exercise the general pair rule with a
non-singleton first component:
\[
  \pairty{x}{\top}{a}{\sing{x}}
  <:
  \pairty{x}{\top}{a}{\top}
\]
and
\[
  \pairty{x}{\top}{A}{\sing{x}..\sing{x}}
  <:
  \pairty{x}{\top}{A}{\bot..\top}.
\]
The first uses \textsc{S-Pair}, reflexivity for the first component, and
\textsc{S-Top} for the member. The second uses \textsc{S-Bounds} under the
pair binder; its lower, upper, and consistency premises are respectively
\textsc{S-Bot}, \textsc{S-Top}, and reflexivity.

The interval case also has a closed end-to-end instance. Bind the identity
function at \(\top\), store the type singleton of that location in a type
pair, ascribe the exact dependent interval
\(\sing{x}..\sing{x}\), and subsume the pair to the interval
\(\bot..\top\). The mechanization constructs its declarative typing
derivation and specializes \cref{thm:safety} to every finite execution from
that term.

\section{Related work}
\label{sec:related}

\paragraph{Dependent object types.}
Foundational DOT systems account for abstract type members, dependent method
types, recursive objects, and rich subtyping
\citep{amin2014foundations,rompf2016dot}. Subsequent proofs factor the
metatheory in different ways, including inert or tight typing
\citep{rapoport2017simple} and definitional-interpreter techniques
\citep{amin2017definitional}. \lambdap{} removes recursive objects,
intersections, and unions and studies paths built from immutable dependent
pairs. The resulting runtime makes allocation order available as a
well-founded measure for the evidence generated by dependent-pair subtyping.

pDOT supports types depending on paths of arbitrary length and uses singleton
types to track path equality \citep{rapoport2019pdot}. Its soundness proof
adapts syntactic DOT techniques and imposes conditions needed for path
lookup. \lambdap{} likewise separates singleton identity from abstract type
selection, while representing record traversal by pair lookup and proving
typed path resolution through store-local realization.

gDOT gives a step-indexed logical-relations model in Iris for a guarded DOT
calculus with recursive types and objects
\citep{giarrusso2020gdot,jung2018iris}. Its surface calculus exposes a later
type former and an explicit coercion term to control guarded recursive
reasoning. The finite \lambdap{} core omits recursion; coercion evidence and
the endpoint stratum induced by allocation order suffice for well-foundedness.

\paragraph{Coercion interpretations.}
Coercion semantics translates subtyping or inheritance derivations into
explicit evidence, making transitivity composition and raising the question
of coherence between multiple derivations
\citep{breazutannen1991coercion,crary2000inclusive}. System FC makes type
equality evidence and casts explicit in a typed intermediate language and
proves erasure before execution \citep{sulzmann2007systemfc}. Our semantic
coercions follow the derivation-directed view of evidence and target endpoint
realization in one store. Type safety requires each compiled derivation to
preserve realization; it does not require different derivations of the same
subtyping judgment to produce equal evidence. The dependent cases retain
source derivations in closures and compile them only after a concrete
location is supplied.

Stratified semantic models have long used worlds or store levels to break
circular definitions involving higher-order state
\citep{ahmed2002stratified}. Value endpoints are ranked by their allocation
position in the immutable store, while type endpoints have rank zero. The
stratum is used solely to justify recursive coercion action at endpoints
stored inside a pair.

\paragraph{Intervals, GADTs, and compilation to DOT.}
Type intervals also support a uniform account of higher-order bounded
abstraction and translucent definitions in
\(F^{\omega}_{..}\) \citep{stucki2021intervals}. \lambdap{} uses first-order
intervals as signatures of abstract pair members and retains explicit
nonemptiness premises in selection, interval formation, and interval
subtyping.

Work on GADT reasoning in Scala and cDOT studies equality and subtyping
constraints recovered by pattern matching
\citep{parreaux2019gadt,boruchgruszecki2022cdot}. Those calculi address
features absent from \lambdap{}, but they reinforce the importance of
tracking the evidence behind path-dependent type refinement. Type-preserving
translations from class-based calculi to DOT address the complementary
question of connecting a source language to a sound path-dependent core
\citep{martres2023compilation}.

\section{Conclusion}

The general dependent-pair rule is sound when its open member premise remains
available until a run-time pair supplies the first-component location.
Store-indexed semantic coercions provide the required proof object. They
compose along transitivity, retain the evidence behind singleton and
selection rules, and transform endpoint realizations without extending the
program syntax. Pair coercion action instantiates its member closure at the
stored component and terminates by descending in the endpoint stratum induced
by the allocation order.

This construction proves progress and preservation for \lambdap{} with
arbitrary paths, abstract interval members, primitive transitivity, and
covariance of both pair components. It also identifies a compact proof
interface for future extensions: typed resolution, endpoint realization,
derivation-directed coercion construction, and a machine invariant whose
subsumption cases are normalized to trailing coercions.
