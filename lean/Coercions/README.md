# Coercions

  Lean formalizations of type-preserving translations from DOT fragments into explicit-coercion calculi.

  - `FCsub`: the type-only explicit-coercion calculus.
  - `ManySortedFC`: an independent many-sorted coercion calculus for type and capture constraints + X for some future X.
  - `DOT` and `Translation`: source fragments and compiler case studies.

  `All.lean` imports the complete development.
