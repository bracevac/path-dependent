# F-sub certificates against FCsub evidence

This directory compares the certificates of [`../Fsub`](../Fsub/README.md) with the coercion evidence of
the repository's `FCsub` on the fragment the two share, plain F-sub. It is a measurement. The
translation has no general typing-preservation theorem; the displayed instances are checked by
FCsub's checker. No term translation is built.

`Translate.lean` embeds F-sub types, contexts and declarative subtyping derivations into FCsub's
syntax, so that one derivation yields evidence on both sides; FCsub's own checker `synthLe` checks the
FCsub side. `Measure.lean` counts nodes of the stored evidence on each side. `Examples.lean` has three
small examples, `Family.lean` a family of bound chains of growing length, and `Depth.lean` narrowing
under arrows and a stress family for the inversion of universals. `Tables.lean` states the computed
tables as theorems that the kernel re-computes. `Family.lean` and `Tables.lean` are generated by the
scripts in `gen/`, which are run from the repository root; `tables.py` reads the recorded `#eval`
output of `Family.lean` and `Depth.lean`, kept beside it as `gen/Family.out` and `gen/Depth.out`.

The modules evaluate their tables with `#eval` when they are built. The library is therefore a target
of its own, `SelectiveFsubCompare`, and is not imported by the DOT development or built by default.

From the repository root:

```sh
lake build SelectiveFsubCompare
lake env lean lean/Coercions/Selective/FsubCompare/Axioms.lean
```
