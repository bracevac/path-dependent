Scala 3's capture checker records in types which capabilities a value may use. This report explains why that record can be trusted, for capture checking over Dependent Object Types (DOT). A first report proved DOT type safe by translating typing derivations into \FCdot, a calculus in which every use of subtyping is explicit evidence that erases. Here subcapturing becomes evidence too, and every binder declares the capabilities its body may use. Beyond type safety the proof needs one theorem about evidence. The roots of a capture set are the capture variables it reaches through the types of its variables. Over a typed store, closed capture evidence that $C$ is below $D$ puts every root of $C$ among the roots of $D$. A use-set half of preservation applies the theorem at each step, so the roots of a run's use set never grow. A run therefore never inspects a variable $x$ for which $\cset{x}$ has a root that its starting use set lacks. A fragment of the calculus shows the shape of the proof on one running example. Capture members, boxes, the compiler's scopes and levels, capability classifiers and front ends follow. The full calculus is mechanized in \Lean.
