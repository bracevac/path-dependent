Scala 3's capture checker records in types which capabilities a value may use. This report explains why that record can be trusted, for capture checking over Dependent Object Types (DOT). A first report proved DOT type safe by translating typing derivations into \FCdot, a calculus in which every use of subtyping is explicit evidence that erases. Here subcapturing becomes evidence too, and every binder declares the capabilities its body may use. Beyond type safety the proof needs one theorem: closed capture evidence relates only capture sets whose resolved capabilities are included. With it, the capabilities a run's use set resolves to never grow. So a run never inspects a variable that resolves to a capability its starting use set lacks. A fragment of the calculus shows the whole proof on one program. Capture members, boxes, the compiler's scopes and levels, capability classifiers and front ends follow, all mechanized in \Lean.
