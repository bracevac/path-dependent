Scala 3's capture checker records in types which capabilities a value may use. This report explains why that record can be trusted, for capture checking over Dependent Object Types (DOT). A first report proved DOT type safe by translating typing derivations into \FCdot, a calculus in which every use of subtyping is explicit evidence that erases. Here subcapturing becomes evidence too, and every binder declares the capabilities its body may use. Beyond type safety the proof needs one theorem about evidence: closed capture evidence relates only capture sets whose leaves, the capture variables they reach, are included. A use-set half of preservation applies it at each step, so the leaves of a run's use set never grow. A run therefore never inspects a variable with a leaf that its starting use set lacks. A fragment of the calculus shows the whole proof on one program. Capture members, boxes, the compiler's scopes and levels, capability classifiers and front ends follow, all mechanized in \Lean.
